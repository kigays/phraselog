プライバシーポリシー

フレーズログ（iOS アプリ）／制定日: 2026年10月26日

フレーズログ（以下「本アプリ」）の開発者（以下「開発者」）は、利用者のプライバシーを大切にし、利用者の情報を収集しない設計にしています。このページでは、本アプリがどの情報を、どこに送り、どこに保存するかを説明します。

1. 開発者が収集する情報

ありません。開発者はサーバーを運用しておらず、本アプリには解析・広告・クラッシュ収集のための外部 SDK も入っていません。アカウント登録もありません。

2. Google（Gemini API）に送る情報

動画の対訳を作るとき、本アプリは、利用者ご自身が登録した Google の API キーを使い、端末から Google の Gemini API へ直接リクエストを送ります。開発者のサーバーは経由しません。

送る情報解析する YouTube 動画の URL、解析の指示文、訳し直しを選んだときの英文（利用者が編集した文を含む）
送らない情報氏名・メールアドレス・端末の識別子・視聴履歴・ほかのノートの内容

送った情報は、Google のプライバシー ポリシーと Gemini API 追加利用規約に従って扱われます。Google の無料枠で API を使う場合、送った内容と生成結果が Google の製品の改善に使われることがあります。本アプリは、初めて送る前に、この内容を説明する画面を表示し、同意を得ます。

3. YouTube の埋め込みプレイヤー

本アプリは、動画の再生に YouTube の公式の埋め込みプレイヤー（YouTube API サービス）を使います。再生時には、YouTube（Google）が自身のポリシーに従って情報を扱います。本アプリは、動画・音声・字幕のファイルをダウンロードも保存もしません。

  • YouTube 利用規約
  • Google プライバシー ポリシー
  • Gemini API 追加利用規約

4. 端末に保存する情報

  • API キー: 端末のキーチェーンに保存します。この端末だけに残り、iCloud キーチェーンには同期しません。
  • ノート・対訳・復習カード・学習の記録: 端末の中に保存します。
  • iCloud 同期（Pro）: オンにした場合、ノートと復習カードは、利用者ご自身の iCloud（CloudKit のプライベートデータベース）に保存されます。開発者はこのデータを読めません。

5. 通知

毎日の復習の通知は、端末の中で予約するローカル通知です。通知のために情報を外部に送ることはありません。

6. お子さまの利用

本アプリは、お子さまの情報を含め、利用者の情報を収集しません。Google の API キーの作成には、Google の利用条件（年齢の条件を含む）が適用されます。

7. 情報の削除

アプリを削除すると、端末に保存された情報はすべて消えます。API キーは、設定の「API キー」から削除できます。iCloud に保存したデータは、iPhone の「設定」→［ユーザ名］→「iCloud」→「ストレージを管理」から削除できます。

8. このポリシーの変更

内容を変更する場合は、このページで告知します。
