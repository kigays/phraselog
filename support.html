よくある質問

API キーはなぜ必要ですか？

動画の英文と和訳を作る解析を、あなた自身の Google（Gemini）の API キーで行うためです。開発者のサーバーを通さないので、1日の上限や広告がなく、アプリは買い切りで提供できます。キーはアプリ内の案内に沿って約3分で作れます。

キーを貼り付けても「確認できませんでした」と出ます

  • キーの前後に空白や改行が入っていないか確かめてください。
  • Google AI Studio で作ったキーか、Google Cloud で「Generative Language API」が有効になっているか確かめてください。
  • お住まいの地域で Gemini API が使えない場合は、確認できません。

お金はかかりますか？

アプリの基本機能は無料です。自分の動画からのノートは、無料で累計10件まで作れます。Pro（1,500円・買い切り）にすると無制限になります。月額料金はありません。キーの費用（Google の無料枠を超えた場合）は Google への支払いで、アプリの価格とは関係ありません。

使えない動画があります

公開されている動画だけが対象です。非公開・限定公開の動画、ライブ配信中の動画、投稿者が埋め込みを許可していない動画、60分を超える動画は使えません。

英文の区切りや和訳がずれています

英文と和訳は AI が生成するため、ずれや誤りが含まれることがあります。1文ループ中に「開始・終了 ±0.2秒」のボタンで区切りを直せます（後ろの文にも自動で反映されます）。文の長押しで、英文と和訳を編集できます。

機種変更したらデータはどうなりますか？

Pro の iCloud 同期をオンにしていれば、新しい端末に引き継がれます。API キーは引き継がれないので、新しい端末でもう一度登録してください。購入済みの Pro は、課金画面の「購入を復元」で戻せます。

返金したい

App Store での購入の返金は Apple が受け付けています。reportaproblem.apple.com から手続きしてください。
